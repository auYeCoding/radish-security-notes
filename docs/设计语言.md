# 设计语言

本文档定义项目的设计语言与 token, 是 `src/renderer/src/styles/` 下四个样式文件的成文依据. 每项取值都来自用户在 frontend-skeleton 与 frontend-router 流程中的逐项选择, 决策原话见 `.navigator/orders/0009-frontend-skeleton/artifacts/decision-log.md`.

## 方向

| 项目     | 选择                                                                                            |
| -------- | ----------------------------------------------------------------------------------------------- |
| 产品气质 | 可信, 克制, 冷静, 专业; 页面整体简约, 排版整齐划一, 信息密度中等, 操作明确                      |
| 风格基调 | 极简与瑞士风格 (Minimalism & Swiss Style): 留白, 网格, 高对比, 几乎无阴影, 单一强调色, 明暗两套 |
| 配色方向 | 保险库深蓝加安全绿: 深蓝 `#1e3a5f` 为主色, 安全绿为强调色, 中性色取石板灰                       |
| 品牌声音 | 简洁中性, 陈述事实: 短句, 不拟人, 不用感叹号, 动作用动词, 报错说明原因与下一步                  |
| 圆角     | 控件 6px, 容器 8px                                                                              |
| 字体     | 打包 Inter (拉丁字符与数字) 加 Noto Sans SC (汉字), 等宽用系统的 Cascadia Mono 与 Consolas      |
| 动效     | 克制三档, 只定义时长与曲线 token, 本阶段不接 gsap                                               |

## 三层 token

| 层      | 文件                                            | 内容                                                                           | 谁可以引用                 |
| ------- | ----------------------------------------------- | ------------------------------------------------------------------------------ | -------------------------- |
| 第 1 层 | `src/renderer/src/styles/tokens.primitives.css` | 原始值: 色阶, 间距单位, 圆角, 字体栈, 时长与曲线                               | 只有第 2 层                |
| 第 2 层 | `src/renderer/src/styles/tokens.semantic.css`   | 语义: 背景, 前景, 主色, 强调色, 边框, 圆角, 间距, 字体, 动效; 明暗两套靠换指向 | 第 3 层, `theme.css`, 页面 |
| 第 3 层 | `src/renderer/src/styles/tokens.components.css` | 组件与布局尺寸: 控件高度, 侧栏宽度, 列表宽度, 顶栏高度, 列表行高               | 页面                       |

`theme.css` 把语义层映射到 Tailwind 的 `@theme`, 页面只写 Tailwind 的语义类名, 例如 `bg-background`, `text-muted-foreground`, `border-border`. 原始颜色与尺寸字面量只能出现在第 1 层, 由 Stylelint 与 ESLint 强制.

`--base-surface-light` 与 `--base-surface-dark` 必须是十六进制字面量, 主进程建窗时读取它们作为窗口背景色, 保证首帧无白闪.

## 颜色

石板灰取自 Tailwind 的 slate 色阶; 深蓝色阶以主色 `#1e3a5f` 的 OKLCH 色相与色度为基准, 按明度推导; 安全绿与警示红取自 emerald 与 red 色阶.

| 语义 token                     | 用途                      | 浅色                  | 深色                  |
| ------------------------------ | ------------------------- | --------------------- | --------------------- |
| `background`                   | 页面背景                  | `#ffffff`             | `#0f172a`             |
| `foreground`                   | 正文                      | slate-900 `#0f172a`   | slate-50 `#f8fafc`    |
| `card`                         | 卡片                      | `#ffffff`             | slate-900 `#0f172a`   |
| `popover`                      | 弹层                      | `#ffffff`             | slate-800 `#1e293b`   |
| `primary`                      | 主按钮填充                | navy-700 `#1e3a5f`    | navy-300 `#96b7e3`    |
| `primary-foreground`           | 主按钮文字                | `#ffffff`             | navy-900 `#112034`    |
| `secondary`, `muted`, `accent` | 次要填充, 悬停与选中底色  | slate-100 `#f1f5f9`   | slate-800 `#1e293b`   |
| `muted-foreground`             | 辅助文字                  | slate-600 `#475569`   | slate-400 `#94a3b8`   |
| `brand`                        | 强调色: 选中指示, 验证码  | emerald-700 `#047857` | emerald-500 `#10b981` |
| `brand-foreground`             | 强调色填充上的文字        | `#ffffff`             | slate-950 `#020617`   |
| `destructive`                  | 破坏性操作                | red-600 `#dc2626`     | red-400 `#f87171`     |
| `border`                       | 分隔线, 容器边框 (装饰性) | slate-200 `#e2e8f0`   | slate-700 `#334155`   |
| `input`                        | 输入框边框 (界面组件边界) | slate-450 `#8495ad`   | slate-500 `#64748b`   |
| `ring`                         | 焦点环                    | navy-700 `#1e3a5f`    | navy-300 `#96b7e3`    |
| `sidebar`                      | 侧栏底色                  | slate-50 `#f8fafc`    | slate-925 `#0b1224`   |
| `sidebar-foreground`           | 侧栏文字                  | slate-900 `#0f172a`   | slate-50 `#f8fafc`    |
| `sidebar-border`               | 侧栏边框                  | slate-200 `#e2e8f0`   | slate-800 `#1e293b`   |

强调色只用于选中指示, 验证码与少数需要突出的地方; 红色只用于破坏性操作, 状态不只靠颜色区分.

| 色对                    | 浅色  | 深色  |
| ----------------------- | ----- | ----- |
| 正文 / 背景             | 17.85 | 17.06 |
| 辅助文字 / 背景         | 7.58  | 6.96  |
| 辅助文字 / 填充底色     | 6.92  | 5.71  |
| 主按钮文字 / 主按钮     | 11.50 | 7.95  |
| 强调色 / 背景           | 5.48  | 7.04  |

## 字体与字号

| 项目     | 取值                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------- |
| 无衬线   | `"Inter Variable", "Noto Sans SC Variable", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif` |
| 等宽     | `"Cascadia Mono", Consolas, "Courier New", monospace`, 用于密码与验证码                              |
| 字体来源 | `@fontsource-variable/inter` 与 `@fontsource-variable/noto-sans-sc`, 随应用打包, 不依赖网络          |

页面把 `html` 的 `lang` 同步为 `zh-Hans` 或 `en`, 浏览器据此选择字形.

| 层级 | Tailwind 类             | 字号 / 行高 | 用途               |
| ---- | ----------------------- | ----------- | ------------------ |
| 标题 | `text-xl font-semibold` | 20 / 28 px  | 详情标题           |
| 正文 | `text-sm`               | 14 / 20 px  | 全部界面正文, 默认 |
| 辅助 | `text-xs`               | 12 / 16 px  | 计数, 标签, 说明   |

字号不小于 12px; 字重用 400 (正文), 500 (按钮), 600 (标题与列表标题).

## 圆角, 间距与密度

| 项目     | 取值                                                                                                  |
| -------- | ----------------------------------------------------------------------------------------------------- |
| 圆角     | 控件 6px (`rounded-lg`), 容器 8px (`rounded-xl`), 小元素 `rounded-md` 为 4.8px, `rounded-sm` 为 3.6px |
| 间距基准 | 4px, 对应 Tailwind 的 `--spacing`, 全部间距取 4px 的倍数                                              |
| 控件高度 | 32px                                                                                                  |
| 列表行高 | 60px                                                                                                  |
| 阴影     | 默认不用, 层级靠 1px 边框与底色区分                                                                   |

## 动效

只定义 token, 不接 gsap, 具体动效留给后续的动效切片. Tailwind 的默认过渡时长与曲线已指向下表的 `base` 与 `ease`, Shadcn 组件自带的过渡与进出场类名因此统一使用同一套时长与曲线.

| token                               | 取值                            | 用途                 |
| ----------------------------------- | ------------------------------- | -------------------- |
| `--motion-fast`                     | 120ms                           | 悬停, 按下           |
| `--motion-base`                     | 200ms                           | 展开, 选中           |
| `--motion-slow`                     | 320ms                           | 面板切换             |
| `--motion-fast-exit` 至 `slow-exit` | 84ms, 140ms, 224ms (进场的 70%) | 退场, 供动效切片使用 |
| `--motion-ease`                     | `cubic-bezier(0.2, 0, 0, 1)`    | 全部过渡             |

系统开启 "减少动态效果" 时, 全部时长置 0ms.

## 组件层 token

| token               | 取值              | 用途             |
| ------------------- | ----------------- | ---------------- |
| `--control-height`  | 32px (间距 x 8)   | 按钮与输入框高度 |
| `--sidebar-width`   | 224px (间距 x 56) | 左侧栏宽度       |
| `--list-pane-width` | 320px (间距 x 80) | 条目列表宽度     |
| `--topbar-height`   | 56px (间距 x 14)  | 顶部搜索栏高度   |
| `--list-row-height` | 60px (间距 x 15)  | 条目列表行高     |

页面用 Tailwind 的括号形式引用, 例如 `w-(--sidebar-width)`.

## 使用规则

- 页面与组件只写语义类名与组件层 token, 不写颜色, 尺寸字面量, 不用任意值类名 (`bg-[#fff]`), 不用行内 `style`.
- 组件只经项目级 Shadcn MCP 引入, 图标库固定为 lucide.
- 切换类控件 (主题, 语言) 的按钮内容不随界面语言变化 (图标, 语言自称), 名称放在无障碍标签与悬停提示里, 切换语言时控件宽度不变; 选中项用主色填充, 不只靠底色深浅.
- 可点击元素的鼠标指针一律是手型 (`globals.css` 的基础样式补回 Tailwind 4 去掉的 `cursor: pointer`), 禁用时是箭头.
- 用户可见文案走 i18n, 语气遵守 "简洁中性, 陈述事实".
- 明暗两套都要检查对比度, 状态不只靠颜色区分, 焦点环不得移除.
