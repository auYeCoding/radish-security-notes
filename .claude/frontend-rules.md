# 前端骨架软约束

写这个前端文件前, 先自检:

- **复用优先**: 库里有没有现成组件? 有就用库, 不够就用项目 `components/` 里已封装的. 不要另起.
- **禁手搓等价控件**: 不要用 `div` 加 state 手搓与库等价的复合控件 (Dialog, Dropdown, Tooltip, Modal 等). 库里有就用库.
- **2 次即抽象**: 这类 UI 是否已在项目里出现第 2 次? 是则抽象为可复用组件, 不要复制粘贴.
- **组件先于页面**: 页面只从项目 `components/` 取组件, 不在页面里现搓基元.
- **样式走 token**: 颜色, 间距, 圆角等一律用语义层 token, 不写死, 不引原始值层.
- **文案走 i18n**: 不硬编码用户可见文案.
- **切换类控件宽度不随语言变**: 主题, 语言这类按钮用图标或语言自称做内容, 名称放无障碍标签与悬停提示, 切换语言时宽度不变; 其它文字容器不写死宽度.
- **可点击元素用手型指针**: 基础样式已补回, 新增可点击元素不要再改指针.

硬约束 (依赖方向, 禁裸原生控件, 禁任意值类名, 禁行内 style, 无障碍) 由 ESLint 与 Stylelint 执行, 不在此列.
